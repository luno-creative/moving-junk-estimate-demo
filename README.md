# 引越し・不用品回収 見積もりデモ

## サービス概要

引越し・不用品回収のサービスを切り替え、間取りや荷物量、移動距離、建物の階数などを入力することで、概算料金を自動計算できるWeb見積もりツールです。

引越しと不用品回収、それぞれのサービス内容に応じた料金の目安を確認できます。

## デモサイト

https://luno-creative.github.io/moving-junk-estimate-demo/

## 主な機能

- 引越し・不用品回収のサービス切り替え
- 間取りの選択
- 荷物量の選択
- 移動距離の入力・選択
- 建物の階数・階段条件の設定
- 梱包サービスオプション
- 家電回収オプション
- 選択内容に応じた料金の自動計算
- 見積もり内容の確認

## 使用技術

- HTML
- CSS
- JavaScript

## 操作方法

1. デモサイトにアクセス
2. 引越しまたは不用品回収を選択
3. 間取り・荷物量などの条件を入力
4. 距離や階段などの条件を設定
5. 必要に応じて追加オプションを選択
6. 自動計算された概算料金を確認

## 制作目的

引越し業者・不用品回収業者向けのWeb見積もりシステムのデモとして制作しました。

料金体系が複雑になりやすいサービスにおいて、見積もり業務の効率化と問い合わせ前の顧客満足度向上を目的としています。

## 注意事項

本サイトは営業・提案用のデモサイトです。

表示される料金やサービス内容はサンプルであり、実際の事業者の料金体系を示すものではありません。
